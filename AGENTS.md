# LinguaVault - Project Instructions & Guidelines

## 🌟 UI/UX Pro Max Standards
All web and mobile code in this project must strictly comply with the **`ui-ux-pro-max`** skill guidelines:
1. **Design System**: Use defined CSS variables and design tokens (`--bg-primary`, `--bg-card`, `--accent-primary`, `--radius-xl`, `--transition-bounce`).
2. **Glassmorphism & Depth**: Surfaces must have subtle backdrop blur, refined borders (`rgba(255,255,255,0.08)`), and soft ambient hover glows.
3. **Micro-Interactions**: Use smooth cubic-bezier transitions for buttons, card hovers, modal pops, sound wave animations, and toast notifications.
4. **Accessibility & Keyboard Shortcuts**: Maintain full support for `Cmd+K` Command Palette, `Space` for flashcard flips, and `1-4` for SRS grading.
5. **Zero-Budget & Local-First**: Keep backend running on Node native SQLite, 0đ cloud dependencies, and optional free Google Gemini AI integration.
